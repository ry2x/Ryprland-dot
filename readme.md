# Ryprland-dotfile

![Ryprland desktop with Rystal-shell](./Ryprland.png)

This repository contains my personal desktop configuration with [Hyprland](https://hypr.land), a dynamic tiling Wayland compositor, featuring a modular Lua configuration and **[Rystal-shell](https://github.com/ry2x/Rystal-shell)** (a custom GTK4 desktop shell built on Aylur's GTK Shell / Astal).

> [!IMPORTANT]
> This repository is maintained for personal use and kept up-to-date with Hyprland changes. Please review configurations and backup your existing dotfiles before applying.
