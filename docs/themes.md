# Themes and wallpapers

Ryprland provides an extended `theme-switch.sh` that updates Rystal-shell and the other
Matugen-managed desktop themes. The selected mode is independent from the wallpaper and is
stored below `${RYSTAL_SHELL_STATE_DIR:-${XDG_STATE_HOME:-$HOME/.local/state}/rystal-shell}/theme`.
Hyprland runs `theme-switch.sh refresh` after
restoring the wallpaper daemon, so the saved mode is reapplied during login.

## Commands

```bash
# Apply and save a mode using the current wallpaper
theme-switch.sh mode light
theme-switch.sh mode dark

# Toggle or display the saved mode
theme-switch.sh toggle
theme-switch.sh status

# These commands preserve the saved mode
theme-switch.sh set /path/to/wallpaper.jpg
theme-switch.sh random
theme-switch.sh refresh

# Compatibility syntax: select a mode while applying a wallpaper
theme-switch.sh --light set /path/to/wallpaper.jpg
```

An installation without saved mode state defaults to `dark`. Theme and asset generation is
published before the new mode is recorded, so a failed generation does not report the requested
mode as successfully applied.

## GTK integration

The extended switcher also updates `org.gnome.desktop.interface` for GTK and the Settings portal.
Light mode uses `prefer-light`, `Materia-light`, and `Ars-Light-Icons`; dark mode uses
`prefer-dark`, `Materia-dark`, and `Ars-Dark-Icons`.

On Arch Linux / CachyOS, install both GTK theme variants with:

```bash
sudo pacman -S materia-gtk-theme
```

Run `theme-switch.sh refresh` to apply the themes using the saved mode and current wallpaper.

The Matugen-generated `gtk.css` supplies the matching dynamic surface and accent colors. Running GTK applications may receive the preference change live, but
should be restarted when they do not reload the generated CSS completely. `xdg-desktop-portal-gtk`
must be installed; `materia-gtk-theme` provides the GTK themes under `/usr/share/themes`.
The Ars icon themes must be available below the corresponding icon data directory;
`Ars-Dark-Icons` uses Breeze as a fallback.

## Qt integration

Qt6 applications use `qt6ct` as their platform theme and Kvantum as their widget style. `qt6ct`
keeps a mode-neutral configuration with the color-scheme-aware `breeze` icon theme; Kvantum owns
the dynamic widget palette and SVG assets generated by Matugen. Generated files live in the
ignored `Kvantum/matugen-generated` theme, separate from the tracked templates, so switching modes
does not dirty the repository. Already running Qt applications may need to be restarted. Qt5 is not
part of the initial synchronized theme scope.
